# Jalan Jalan

Project Tugas 8 menggunakan Vue.js dan Vite dengan tema aplikasi pencarian destinasi wisata Indonesia.

## Fitur
- Pencarian destinasi
- Filter kategori
- Simpan/hapus destinasi favorit
- Tampilan detail perjalanan
- Desain responsif untuk desktop dan mobile

## Menjalankan project

```bash
npm install
npm run dev
```

Kemudian buka alamat lokal yang ditampilkan Vite, biasanya `http://localhost:5173`.

## Build production

```bash
npm run build
```
